Cellular Automaton Zoo

CS378 Project 1 · a Dart cellular automaton simulator built with classes and mixins

What it is

A grid of cells that are alive or dead and change over discrete time steps by following local rules. The default rule is Conway's Game of Life (B3/S23): a dead cell with exactly 3 live neighbors is born, and a live cell with 2 or 3 live neighbors survives. Changing the B/S numbers produces different behavior.

Design

  • Grid and Cell: board state and cell coordinates, with bounds checking.
  • CellularAutomaton: abstract subclass of Grid with step(), nextState() and render().
  • ConwayRules: mixin implementing the B3/S23 rule.
  • AsciiRenderable and DecoratedRenderable: mixins for plain and bordered output, using on constraints.

Run it

dart pub add args
dart run bin/cellular_automaton.dart --species=conway --width=30 --height=15 --generations=100 --fps=8
