# Grading Agent

## Background
This repository contains a starter project for a class that teaches the Flutter Framework for Mobile Development. The first assignment of this class is designed as a introductory exercise to get familiar with the Dart programming language. The spec for the project is inside [/README.md](/README.md) and some starter code described by it is in [/bin](/bin) and [/lib](/lib). 

The submission format for the project is also mentioned in the [README.md](/README.md) file.

## Claude as a co-grader

You, Claude, will work with me, the TA of the class to help grade the projects. 

## Extracting student submissions
The submissions are inside the [/submissions](/submissions/) folder. Each submission is a .zip file that you will need to extract. The extracted files can go inside a separate folder [/submissions/extracted](/submissions/extracted).

## The grading rubric

The grading rubric lives in the file [/RUBRIC.md](/RUBRIC.md). It consists of four parts:
- Grading the code under the folder `cellular_automaton_zoo` inside the student submission. This is the dart code.
- Grading the file `spec.pdf`. Which descibes the code.
- Grading the file `llm-usage.pdf`. Cotnains how the student used LLMs for the project.
- Grading the video `tutorial.mp4`. Where the student demonstrates their understadning of the project by adding a small feature to it.


## Grading the submissions

One the submissions are extracted, the TA needs help on grading the code under `cellular_automaton_zoo`, the code description under `spec.pdf`, the `llm-usage.pdf` report. The `tutorial.mp4` video will be graded manually by the grader.

## Storing the results

Under the folder [/submissions/grades](/submissions/grades) is where the grades of the projects will live. This is where you, claude, will store the grades. Create a markdown file per student and with the exact name as their zip file. Then use the [/RUBRIC.md](/RUBRIC.md) to create a table for the points, in the table mention the total points and the points scroed. Mention any notes that stood out to you and may need attention of the TA to take a manual look for that particualr graded item.

At the end of the file, create a small note upto 250 words describing how this student's submission is unique.
